# Каталог товаров

Простой каталог товаров на Laravel с сортировкой, пагинацией и группами. Тестовое для EquipGroupRu.

## Основные возможности

- Список групп первого уровня и товары на главной странице.
- Сортировка товаров по цене и по названию в обе стороны.
- Пагинация товаров.
- При выборе группы показываются товары этой группы и всех её подгрупп.
- Карточка товара с названием, ценой и хлебными крошками по группам.
- Адаптивная верстка на Bootstrap, режимы списка и сетки.

## Решения

- В целом, контроллер можно было бы разнести на сервисы, однако с текущим функционалом это не требуется.
- Касаемо getProductsCountAttribute() и логики подсчета, ее по хорошему делать CTE, либо иметь поле products_count и обновлять при изменении товаров, но с текущими объемами, нынешнее решение справляется.

## Запуск проекта

1. Скопировать пример окружения:

```bash
cp .env.example .env
```

2. Установить зависимости:

```bash
composer install
npm install
npm run build
```

3. Запустить миграции и сиды:

```bash
php artisan migrate
php artisan db:seed
```

4. Запустить приложение:

```bash
php artisan serve
```

5. Открыть в браузере:

```
http://127.0.0.1:8000
```

## Docker

```bash
docker compose up --build
```
ВАЖНО: При запуске с докера, прокидывается автоматически тестовый дамп.

## Что интересного

- сортировка по цене реализована через join `products` и `prices`;
- подсчет товаров в группах поддерживает вложенные подгруппы;
- интерфейс на Bootstrap, адаптивный переход от списка к сетке;
- карточка товара строит хлебные крошки по иерархии групп.

## Структура данных

- `groups` — иерархия групп с полем `id_parent`;
- `products` — товары, связанные с группой через `id_group`;
- `prices` — таблица цен, связанные с товаром через `id_product`.
